# KM Box — помощник кальянного мастера (H-Box: Авиатор / Штаб)

Веб-приложение (работает на телефоне и компьютере, можно «Добавить на экран Домой»):

- **Вход** по логину и паролю; роли «кальянный мастер» и «старший КМ» (админ).
- **Смена** — открытие/закрытие по шаблону: выбор заведения, отметки по пунктам, картинка-«скрин» таблицы с фамилией и датой (закрытие с 00:00 до 04:00 — датой предыдущего дня). Кнопки «Поделиться» (в Telegram с телефона), «Копировать», «Скачать PNG».
- **Постоянные гости** — список, поиск по имени, карточка, редактирование, добавление, «Принять заказ» для гостя (пожелания подставляются).
- **Остатки** — вкладки Авиатор/Штаб, бренды блоками, расход в неделю, «только заканчивается».
- **Инвента** — в воскресенье после 12:30 всплывает «Необходимо заполнить инвенту»; заполняет текущий пользователь, дата сегодняшняя, черновик сохраняется. После заполнения — расчёт заказа и кнопка «Отправить старшему КМ» (копирует текст заказа и открывает чат в Telegram).
- **Приём заказа** — бренды, любимые/нелюбимые вкусы, вкус в основе, крепость, шкала сладкий↔кислый, чаша, жар, кальян (свой список для каждого заведения), тяга, холодок, мята; режим «Гость не разбирается». «Отправить» → лучший микс **из того, что есть в остатках** + 2 альтернативы и таймер на 15 минут (звук, вибрация, уведомление).

## Запуск

Нужен **Node.js 22.13+** (используются встроенные `node:http` и `node:sqlite`, `npm install` не нужен).

```bash
ADMIN_PASSWORD='сложный-пароль' node server/server.js
# открыть http://localhost:3000, войти admin / ваш пароль
```

Переменные: `PORT` (3000), `DB_PATH` (`data/kmbox.db`), `ADMIN_LOGIN` (admin), `ADMIN_PASSWORD` (по умолчанию `admin` — смените сразу).
При первом запуске база создаётся и наполняется из `server/seed.json` (импорт ваших Excel: 26 гостей, ~600 позиций табака и аксессуаров по двум заведениям, история инвент с августа 2026).

Сотрудников заводит старший КМ: **Настройки → Сотрудники**. Фамилия сотрудника подставляется в отчёты смен.
Там же — ник старшего КМ в Telegram и параметры расчёта заказа.

### Docker

```bash
docker build -t kmbox . && docker run -d -p 3000:3000 -v kmbox-data:/app/data -e ADMIN_PASSWORD=... kmbox
```

Для работы с телефонов нужен HTTPS (VPS + Caddy/nginx, или Render/Railway/Fly). Бэкап — файл `data/kmbox.db`.

## Как считается заказ

1. Расход позиции между двумя инвентами = было + заказали − стало (отрицательное = 0), берутся последние ~2 недели → расход в неделю.
2. Нужно = расход/нед × «запас, недель» (1,5) + резерв (30 г) − остаток.
3. Округление вверх до шага бренда (мин. 40 г). Шаги взяты из истории заказов в Excel, Nuar = 200 г, Deus парфюм = 40 г; правятся в «Остатки → Бренд».
Все количества можно поправить руками перед сохранением.

## Как подбирается микс

У каждого вкуса — профиль по названию (ягоды, цитрус, тропики, десерт, напитки, травы, цветы/парфюм, хвоя, мята, холодок…) и кислотность; у бренда — крепость 1–5 (по умолчанию примерная, правится в «Остатки → Бренд»). Алгоритм перебирает пары и тройки вкусов **с остатком ≥ 12 г**, исключает нелюбимое, учитывает любимое, вкус в основе, сочетаемость профилей, целевую крепость и сладость/кислинку, проверяет, хватит ли граммов под выбранную чашу. Если у вкуса профиль определился неточно — при добавлении вкуса можно отметить профиль вручную.

## Структура

```
public/            фронтенд (HTML/CSS/JS без сборки)
  js/logic.js      чек-листы, даты, расчёт заказа, подбор микса
  js/api-remote.js работа с сервером
  js/api-local.js  демо-режим (данные в браузере)
  js/app.js        интерфейс
server/server.js   API + SQLite + авторизация
server/seed.json   стартовые данные из Excel
tools/parse_excel.py  повторный импорт из Excel: python3 tools/parse_excel.py гости.xlsx бланк.xlsx server/seed.json
scripts/build-demo.js сборка однофайловой демо-версии в dist/
```
